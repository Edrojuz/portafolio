# 🌍 Portafolio Web – Eduardo Rojas

Portafolio web personal desarrollado como parte de mi formación Full Stack, integrando diseño moderno con paleta tierra e incorporando animaciones, secciones responsivas y navegación fluida. El objetivo es presentar mis proyectos, habilidades y experiencia combinando **geología** y **desarrollo de software**.

---

## 🚀 Tecnologías Utilizadas

### 🎨 Frontend
- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript (ES6)**
- **jQuery**

### ⚙️ Animaciones y Efectos
- Smooth Scroll
- Fade-in basado en IntersectionObserver
- Navbar colapsable en móvil
- Hover en tarjetas y elementos gráficos
